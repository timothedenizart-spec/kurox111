## Prototype jouable

La démo web ne nécessite aucune dépendance externe :

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Puis ouvrir `http://localhost:4173`. Les vérifications automatisées s’exécutent avec :

```bash
npm test
```
