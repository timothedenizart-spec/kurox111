# Modèle de transfert entre agents

Copiez ce modèle dans le commentaire de l’issue #1 ou dans une nouvelle entrée versionnée lors d’un transfert de responsabilité.

```md
## Transfert : <identifiant de tâche>

- Responsable sortant :
- Responsable entrant :
- Branche et révision source :
- Objectif atteint / restant :
- Fichiers modifiés :
- Contrats ou décisions impactés :
- Tests réellement exécutés et résultat :
- Données, modèles ou runners locaux requis :
- Risques, conflits possibles et étapes de reprise :
- Date UTC :
```
